# 金龙眼睛优化方案（2026-09-25，D42已实现，待实机验证）

原方案经用户确认，已在D42实现。交付目录：`.weapon-fx-work/current/dragon-eyes-d42`。以下保留设计依据；实际落地参数见文末。现有GoldenDragonHeadGlow包含头冠、头部电纹、额头与两颊金光，GoldenDragonBodyFxLink另有12条头部电弧；没有独立定位双眼的光效层。因此眼睛容易被周围亮部淹没，继续加强整头亮度不一定能突出眼神。

建议采用“琥珀金虹膜、深色竖瞳、白金小高光、细窄金边”的组合：

| 层次 | 建议效果 | 目的 |
| --- | --- | --- |
| 眼球基础 | 琥珀橙金虹膜，深色竖瞳，保留深色眼眶边缘 | 明确视线和威严感；普通外观也有眼神 |
| 眼内高光 | 上前方一个小白金亮点，亮点面积约虹膜的10%起调 | 产生眼球湿润与立体感，保留瞳孔 |
| 贴眼金光 | 两眼独立、低强度光晕，范围从眼眶宽的1.1倍起调 | 正常游戏视距能识别两个小金点；近看仍清楚 |
| 轻微呼吸 | 约2.5秒一轮、亮度上下10%起调 | 少量生动感，避免强闪烁 |
| 眼尾电弧 | 沿眼尾至眉角的短细黄色电弧，间隔约0.6～1.0秒 | 与现有雷电呼应，保留眼球和瞳孔轮廓 |

上述尺寸、频率均为设计起点，需按真实眼眶校准。先定位并验证双眼，再添加微光，最后决定是否需要电弧；如果被额头/脸颊光覆盖，应局部压低眼周外溢亮度。建议近景用瞳孔/虹膜细节，远景用微光辨认，不扩大成头部光球。

实现建议：读取现有头部或上颌骨的完整骨骼坐标，用双眼各自的局部偏移定位；利用俯仰、转身和咬合动作逐帧检查偏移，不用角色世界坐标估算，也不直接复用脸颊光位置。保留深度遮挡，确保侧视时远侧眼不会透头。此方案不依赖独立眼骨，但不承诺转眼或眨眼；这类表情要另查眼睑/眼球蒙皮。

资格建议沿用现有规则：虹膜/竖瞳属于模型基础细节；新增眼光与电弧归入现有黑金达标特效，普通玩家不新增装备光效。普通/达标、近/远、正/侧/仰视，以及龙珠和头部雷电同时出现时都要检查。

# 高级合成材料重设计方案

版本：2026-06-16

## 设计目标

这版不是修补单个职业，而是把高级合成当成一套完整的装备养成经济重新梳理。

核心目标：

- 锁死 `胜利者的皇冠`：所有防具、盾牌、护体类继续消耗 `胜利者的皇冠 x1`。
- 锁死前置成品装备：所有成品装备继续需要原来的穿戴基底，武器为 10.5 段，防具为 10 段。
- 成品配方不再直接塞大量基础材料，基础材料尽量沉到中间材料里，方便 UI 树状展示。
- 每个职业保留独立材料性格，但总成本接近。
- 部位成本统一：武器最高，胸甲/盾牌/护体次之，头腿鞋中等，手腕护臂最低。

## 成本权重

| 部位 | 成本权重 | 设计说明 |
|---|---:|---|
| 武器 | 100% | 不需要皇冠，但需要 10.5 段前置成品，材料量最高 |
| 盾牌 / 护体 | 85% | 副手价值高，材料接近武器但略低 |
| 衣服 / 铠甲 / 法袍 | 80% | 主防具，核心材料较多 |
| 头盔 / 帽子 | 55% | 中等成本 |
| 护腿 / 鞋 | 55% | 中等成本 |
| 护臂 / 护腕 / 手 | 35% | 最低成本，但仍消耗皇冠和前置成品 |

## 通用规则

| 类型 | 规则 |
|---|---|
| 武器 | 不消耗 `胜利者的皇冠`，必须穿戴对应 10.5 段前置成品 |
| 防具 / 盾牌 / 护体 | 消耗 `胜利者的皇冠 x1`，必须穿戴对应 10 段前置成品 |
| 通用稀有材料 | 保留 `混合宝石`、`艾拉恩的雅拉无咒文书` |
| 职业掉落材料 | 每个职业使用独立 Boss / 职业掉落材料 |
| 中间材料 | 可点击、可递归展开，承担大部分基础材料消耗 |

## 与原配置相比的关键调整

| 问题 | 调整 |
|---|---|
| 法系直接消耗 `皮带 x2000`，职业感不合理 | 红法和蓝法改为布料、净水、钢绞线、颜料组合 |
| 有些材料是中间件，有些只是大额基础材料，但都混在成品层 | 成品层只放中间材料、通用稀有、职业掉落、锁定材料 |
| 弓手材料线较合理，但 `幻想的宝石装饰品`缺少展开感 | 增加为可合成中间材料，消耗精工石、魔力石、贝壳 |
| `福尔马林混合物`药草 x10000 过重且体验粗暴 | 下调为药草 x1200，让斗士成本仍高但不失控 |
| 各职业总成本不够统一 | 使用统一部位权重控制核心材料、混合宝石、职业掉落数量 |

## 落表建议

1. `胜利者的皇冠` 和所有 `need_source = wear` 的前置成品不改名、不改数量。
2. 武器行继续不加 `胜利者的皇冠`。
3. 新增或补齐 `幻想的宝石装饰品` 的中间材料配方。
4. 如果现有物品表没有某个中间材料的实体道具，优先复用已有名称，不新增显示名。
5. UI 树状展开时，成品下第一层应只出现中间材料、通用稀有、职业掉落、锁定材料；基础材料只出现在中间材料下面。
